## 🌌 Übersicht & Projektbeschreibung
Diese interaktive Web-Bewerbung präsentiert ein umfassendes Lore- und Charakterkonzept für die Besetzung von **Imperator Sheev Palpatine (Darth Sidious)** auf dem Server **Aufbau des Imperiums**.

Entwickelt mit modernstem Vanilla Web-Stack (HTML5, modern CSS3, Canvas 2D Physics & Web Audio API) ohne externe Framework-Abhängigkeiten.

## 🔊 Soundkulisse & Interaktive Features
- **Sofortiger Einstieg & Sound:** Authentische Star Wars Klangteppiche und Effekte direkt im Browser.
- **Echte Star-Wars-Machtblitze:**
  - Physikalisches Canvas-Blitzsystem mit Verästelungen, Leuchtspuren und Schockwellen.
  - Interaktives Zappen bei Klick auf den Hintergrund oder beim Halten auf das Imperator-Thronbild.
  - Sound-Trennung: Klicks auf Buttons und Soundboard-Pads spielen sauber den jeweiligen Clip ab, ohne störende Hintergrundblitze.
- **Echtes Palpatine Soundboard (12 Original-Samples):**
  - *„Good, good...“*
  - *„UNLIMITED POWER!“*
  - *„Do it.“*
  - *„Execute Order 66.“*
  - *„I am the Senate.“*
  - *„Dark Side Power“*
  - *„Everything is proceeding as I have foreseen.“*
  - *Teuflisches Sith-Lachen*
  - *Knuspriges Keks-Knuspern*
  - *Machtblitze-Gewitter*
  - *The Imperial March*
  - *Star Wars Fanfare*
- **Keks-Logistik-Terminal (Keksi-Modus):**
  - Rations-Zähler, Minigame mit Krümel-Beseitigung und schwebende Keks-Partikel per Tastendruck.
- **Flüssige Sprachausgabe:**
  - Automatische Bereinigung von Abkürzungen für natürliche Aussprache im interaktiven Audienz-Simulator.
- **1-Klick Discord-Export:**
  - Komplette Bewerbung formatiert als Markdown mit einem Klick in die Zwischenablage kopieren.
